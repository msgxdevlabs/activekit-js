import { ActiveKit } from '@activekit/sdk';
const ak = new ActiveKit(process.env.AK_KEY);
 
// 1. tell ActiveKit something happened
await ak.events.track({
  name: 'referral.completed',
  user: 'u_8412',
  meta: { plan: 'growth', seats: 12 }
});
 
// 2. pay out from your own ledger
ak.webhooks.on('payout.created', async (p) => {
  await credits.grant(p.user, p.credits);
});

Quickstart

Four steps, one afternoon

01
Install the SDK

One package, no peer dependencies, typed end to end.

npm i @activekit/sdk
02
Point at a ledger

Name the credit balance you already meter. Sandbox mirrors production caps.

ledger: 'prod-credits'
03
Track one event

Send the signal you already emit. Names are yours, not ours.

ak.events.track(...)
04
Handle the payout

Grant credits in your own code. We sign, retry, and record every attempt.

on('payout.created')

Webhooks

Signed, idempotent, replayable

Every payout carries a deterministic key, so a retried delivery grants credits once. Failed deliveries queue for 72 hours and can be replayed from the dashboard or the API.

HMAC-SHA256 signature on every body
Idempotency key per payout attempt
